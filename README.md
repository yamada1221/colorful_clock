# 背景色変化時計

端末の現在時刻に合わせて、背景色が毎秒変わる時計です。

## BGM版

「BGMを再生」を押すとループ再生します。初期音量は25%です。

- 自動：端末の現地時間で6:00〜17:59は「スターライトパフェ」、18:00〜翌5:59は「プラネタリウム」。
- 「昼の曲」「夜の曲」で固定できます。切替時は5秒間クロスフェードします。
- 音量と選曲モードをこのブラウザに保存します。ページを開き直したときは停止状態です。
- 音源を同梱しているため、再生時に配布サイトへの接続は不要です。

`index.html` と `bgm.js`、`assets` を同じ構成で配置してください。ローカルでは `python -m http.server 8000` で起動し、http://localhost:8000 を開けます。

## 音楽・利用条件

音楽：BGMer https://bgmer.net/

- [スターライトパフェ](https://bgmer.net/music/333/)（SHORT版、2:47）
- [プラネタリウム](https://bgmer.net/music/362/)（SHORT版、1:52）

著作権・原盤権はBGMerに帰属します。音源はWeb用にMP3 96kbpsに変換しています。配布時にも出典と権利帰属を維持してください。
