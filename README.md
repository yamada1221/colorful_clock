# 背景色変化時計

端末の現在時刻に合わせて、背景色が毎秒変わる時計です。

## BGM版

普段は時計だけを表示します。画面のタップ・クリックで操作UIを表示し、操作が終わって6秒経つと隠れます。操作UIの外をもう一度タップするか、Escapeでも隠せます。音楽はUIを隠しても再生し続けます。キーボードで操作中と選曲リストを開いている間は自動で隠れません。

三角の再生ボタンを押すとBGMが流れ、再生開始後は四角の停止ボタンに切り替わります。初期音量は25%です。

音量は0.1刻みで調整できます。小音量側を細かく調整できる二乗カーブを使い、0は完全な無音、100は音源の最大音量です。保存済みのスライダー位置もそのまま引き継ぎ、従来より小さな音量になります。

- 自動：端末の現地時間で6:00〜17:59は昼の3曲、18:00〜翌5:59は夜の3曲を順番に再生します。
- 太陽・月のマークで昼・夜に固定できます。絵文字は使っていません。
- 曲名のリストから選曲できます。最後の曲が終わると最初の曲へ戻ります。切替時は5秒間クロスフェードします（曲終了後は次曲を再生）。
- 音量と選曲モードをこのブラウザに保存します。ページを開き直したときは停止状態です。
- 音源を同梱しているため、再生時に配布サイトへの接続は不要です。

`index.html` と `bgm.js`、`controls.js`、`assets` を同じ構成で配置してください。ローカルでは `python -m http.server 8000` で起動し、http://localhost:8000 を開けます。
